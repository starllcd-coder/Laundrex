# Laundrex App Introduction (English)

## Overview
Laundrex is an end-to-end laundry operations platform that combines point-of-sale, order tracking, pickup and delivery management, payments, reporting, and staff/branch administration in one system. It is designed for daily store operations with clear workflows and quick access to the most-used actions.

## Core Features
- **POS (Point of Sale)**: Create new orders, add services/items, apply discounts, and print receipts.
- **Orders**: Search, filter, and manage order statuses from a list or a kanban view.
- **Pickup Counter**: Lookup orders by QR or number for fast handover and status updates.
- **Delivery**: Assign drivers, schedule time slots, set delivery fees, and track delivery status.
- **Payments**: Record and review payments, references, and balances.
- **Customers**: Manage customer profiles, VIP settings, loyalty points, and order history.
- **Reports**: Daily Z reports and summaries with print support.
- **Management & Settings**: Branches, staff, permissions, catalog, taxes, and WhatsApp templates.
- **Multi-language**: English and Arabic UI with RTL support.

## Typical Workflow
1) **Create Order**: POS -> New Order -> Add items/services -> Save or Save & Print.
2) **Track Status**: Orders list or Kanban -> Advance status (Received → Washing → Ironing → Ready → Delivered).
3) **Pickup**: Pickup Counter -> Scan QR or type order number -> Mark Ready/Delivered.
4) **Delivery**: Delivery List -> Open order -> Assign driver, slot, fee -> Save Delivery.
5) **Payment**: Collect payment from order detail if balance remains.
6) **Reporting**: Print daily Z report for reconciliation.

## Windows and What They Do

### Dashboard
- Overview of today’s performance, quick KPIs, and recent activity.
- Entry point for navigation to high-traffic areas.

### POS - New Order
- Build a new order with items/services, quantities, and prices.
- Apply discounts and confirm totals.
- Save order or save and print a receipt.

### Orders List
- Filter by order number, customer phone, status, branch, date, and flags (urgent/unpaid).
- Open any order to view full details.
- Advance order status when appropriate.

### Orders Kanban
- Visual workflow board grouped by status.
- Quick access to order actions.

### Order Detail
- Full view of order items, totals, customer data, and history.
- Actions: mark urgent, reprint receipt, advance status, cancel.
- WhatsApp messaging and log tracking (if enabled).

### Pickup Counter
- Fast lookup via QR or order number.
- Mark orders as ready or delivered.
- Reprint receipt if needed.

### Delivery List
- Monitor delivery orders and statuses.
- Filter by driver, branch, date, or status.

### Delivery Detail
- Assign driver, slot, address, fee, and notes.
- Save delivery updates and view order summary.

### Payments
- List of recorded payments and references.
- Payment capture is also available in the order detail view.

### Customers
- Search and open customer profiles.
- Edit profile, VIP status, preferred language, WhatsApp opt-in, and notes.
- View customer order history.

### Reports
- Daily summaries and Z report with print option.

### Management
- Branch and staff management.
- Audit logs and permissions (based on role).

### Settings
- Catalog configuration, pricing, taxes, and system preferences.
- WhatsApp templates and messaging options.

## Roles and Permissions
- Roles (e.g., Admin, Manager, Cashier, Worker) control access to sensitive actions.
- If you cannot see or edit a page, ask your admin to adjust permissions.

## Language & RTL Support
- Use the top bar to switch English/Arabic.
- Arabic UI uses RTL layout with aligned headings and controls.

## Tips
- Use filters in Orders to find requests quickly.
- Print receipts from order detail if a customer needs a copy.
- Keep delivery info updated to avoid missed handovers.

## Support
Contact your system administrator for access issues or configuration changes.
